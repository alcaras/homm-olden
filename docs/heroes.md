# Heroes — Starting Skills, Stats & Armies

<p class="lede">All 108 stock heroes (six factions × two classes × nine heroes), with starting stats, starting skills, starting army composition, and the hero's signature specialization.</p>

Within each faction, ⚔ heroes are the Might class, ✦ are Magic. Stats columns: <strong>A</strong>ttack, <strong>D</strong>efense, <strong>P</strong>ower (Spell Power), <strong>K</strong>nowledge. Skill levels are L1 / L2 (basic / advanced). Each hero starts with the faction skill plus one other; a few start with the faction skill at L2 instead.
